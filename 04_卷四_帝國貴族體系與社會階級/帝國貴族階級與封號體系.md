# 帝國貴族階級與封號體系

社會階級森嚴，貴族的權力與地位根據其爵位有著明確的劃分與規範。

## 🏅 帝國九大階級劃分

| 等級 | 稱號 | 權責與地位說明 |
| :--- | :--- | :--- |
| **I** | 皇帝/女皇 | 絕對君主，擁有所有土地名義上的所有權與最高法權。 |
| **II** | 王爵 (PrinceDuke) | 皇族旁支或皇室授予之高爵，統轄大區級領地，擁有獨立軍政外交權，與大公同等但具皇室血統／授勳象徵。 |
| **II** | 大公 (GrandDuke/Duchess) | 帝國級總督，掌管一大區域或是大公國，擁軍權與總議會席位。 |
| **III** | 公爵 (Duke) | 掌握大區，直屬於皇室，擁有軍事與外交權。 |
| **IV** | 侯爵 (Marquess) | 邊境或戰略要地總督，有軍政合一指揮權。 |
| **V** | 伯爵 (Count/Countess) | 中型領地領主，負責地方法律、商貿與防衛。 |
| **VI** | 子爵 (Viscount) | 小城市或戰略村鎮領主，兼有民政與軍備責任。 |
| **VII** | 男爵 (Baron) | 最基層的榮譽貴族/軍功領主，可在一定情況下晉爵。 |
| **VIII** | 騎士 (Knight) | 附屬於某家族或領地的功勳者，無領地，擁軍職或特務職能。 |
| **IX** | 上流平民 (紳士) | 無頭銜但受承認的上層階級，為商人、學者、富裕平民等。 |

* **附屬貴族系統**：非完全獨立掌權，但依附於高等貴族家族、具特定功勳或役務職能的貴族階層。這些人常無實際領地，但有貴族地位與軍政責任，構成主貴族勢力的輔助系統。

## 👥 貴族成員正式稱謂補充

| 身分 | 稱謂（正式） | 補充說明 |
| :--- | :--- | :--- |
| **家主** | 公爵殿下／侯爵殿下等 | 依爵位變化，如王爵則為「王爵殿下」。 |
| **家主配偶** | 公爵夫人殿下／侯爵夫人殿下 | 或「星空夫人」「銀森夫人」等領地尊稱。 |
| **嫡長子** | 小公爵殿下／小侯爵殿下 | 若已被指定繼承人，也可稱「繼承卿殿下」。 |
| **嫡長女** | 卿殿下／（名）卿 | 若未指定為繼承人，仍具高社交地位。 |
| **嫡次子／次女** | 卿殿下 | 較年幼者亦可用「少卿殿下」稱呼。 |
| **嫡姊／嫡弟** | （名）卿殿下 | 若已婚，可能改稱為配偶家的夫人／公子等。 |
| **嫡系未成年子女** | 小卿殿下／少卿殿下 | 具貴族身份但無繼承順位，視年齡稱呼調整。 |
| **叔父／伯父／姑父** | （名）老卿／（名）卿大人 | 視年齡輩分，常用於尊稱年長貴族。 |
| **姨母／姑母／嬸母** | （名）夫人／（名）卿夫人 | 已婚女性貴族通常冠以配偶家族之姓與爵位稱。 |
| **堂兄姊／堂弟妹** | （名）卿殿下／少卿殿下 | 貴族子弟間的日常稱謂，等級略低於嫡系直屬。 |
| **外祖父母（母系）** | 尊老殿下／外卿殿下 | 若其家族亦為貴族，會尊稱其本家爵位。 |
| **旁系支族家主** | 卿侯殿下／副侯殿下 | 若封地有實權，會冠以具體地名「○○侯殿下」。 |
| **嫡女，已婚(留本家)**| 卿夫人殿下／（名）卿夫人 | 用以表示既是「卿」階貴族又為已婚女性。 |
| **側/庶女，已婚(留本家)**| （名）夫人／（名）小姐 | 無卿階稱「小姐」；有頭銜者可稱「○○官夫人」。 |
| **已聯姻他族之女** | ○○夫人（冠夫姓） | 例如「希利鄔斯夫人」、「雷本夫人」等。 |
| **無爵/從士出身配偶** | 公子／夫人（不冠姓） | 稱謂保守，不代表擁有完整貴族身份。 |
| **繼子女（由再婚而來）**| 卿殿下（視具體認養與否） | 若未正式收養，稱謂常帶有社交距離。 |
| **幼子／私生子女** | 少卿殿下／（名）公子／小姐| 社交上受限，實際權利依家主態度而定。 |
| **特殊任命或過繼者** | ○○卿殿下／副卿殿下 | 常出現在貴族間政治聯姻與血統延續場合。 |
